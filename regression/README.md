# WDIM regression kit

Tools from the October 2026 What Did I Miss investigation (Bloox issue #442). Use them before shipping any change to a recap prompt, window or background, and compare against the recorded baseline below.

All private inputs and outputs (listener excerpts, character data, ebook text, generated recaps, grades) live in this folder but are gitignored. Never commit them.

## Inputs (private, local only)

| File | What it is |
|---|---|
| `private/feedback_dump.yaml` (or `WDIM_FEEDBACK_DUMP`) | Firestore `feedback` documents with `source = wdim_recap` and diagnostic logs. Each diagnostic holds the transcript excerpt the model saw. |
| `*_characters.json` | Cached character lists from the worker: `GET $WORKER_URL/admin/api/books/{key}/detail` (read-only). |
| `books/*.txt` | Public-domain Gutenberg texts for the safety-filter test (`make_windows.py` downloads nothing; fetch them with the IDs listed in its history). |
| An ebook in `~/Downloads` | Optional source of truth for grading (`align_ebook.py`). |

## Mac (on-device model of the installed macOS)

```bash
swiftc -O main.swift -o guardtest            # default vs permissive guardrails
swiftc -O arms/main.swift -o arms/armstest   # per-prompt instructions, permissive guardrails
python3 build_arms.py && ./arms/armstest arms_passages.json 3 arms_results.jsonl
python3 build_sweep.py && ./arms/armstest mac_sweep_jobs.json 3 mac_sweep_results.jsonl
swiftc -O surfaces/main.swift -o surfaces/surfacestest   # per-prompt token caps
python3 build_surfaces.py && ./surfaces/surfacestest surface_jobs.json 3 surface_results.jsonl  # Last Moments, widget, bookmarks
```

macOS 26.x runs the iOS 26.4-era 3B model. macOS 27 on an M3+/12 GB Mac runs the 20B model (`contextSize` 8192). Updating macOS replaces the model, so older generations can only be retested on a device that still runs them.

## iPhone (`../DeviceEval`)

```bash
cd ../DeviceEval
cp ../regression/device_jobs.json Resources/   # generated by build_sweep.py; private, gitignored
xcodegen generate
xcodebuild -project DeviceEval.xcodeproj -scheme DeviceEval -configuration Release \
  -destination 'id=<device UDID>' -derivedDataPath build -allowProvisioningUpdates build
xcrun devicectl device install app --device <CoreDevice id> build/Build/Products/Release-iphoneos/DeviceEval.app
```

Open "WDIM Eval" on the unlocked phone and tap Start (it resumes if interrupted). Pull results with:

```bash
xcrun devicectl device copy from --device <CoreDevice id> --domain-type appDataContainer \
  --domain-identifier com.eladkatz.wdimdeviceeval --source Documents/results.jsonl --destination device_results.jsonl
```

## Grading

`make_grading.py` / `make_sweep_grading.py <label> <jobs> <results>` build blind packages (random recap IDs, stretch names hidden). Grade them with an AI grader using `GRADER_PROMPT.md`, then score with `score.py` or `score_sweep.py <label>`. When an ebook is available, `make_ebook_grading.py` adds the published text as the source of truth; on the October run it agreed with transcript-only grading on 92% of verdicts.

## Baseline (October 15, 2026; 10 reported excerpts, 30 recaps per row, share misleading)

| Version | 20B (Mac, macOS 27) | 3B (iPhone 16 Pro, iOS 27) |
|---|---|---|
| Production prompt, ~10 min | 53% | 33% |
| Revised prompt + background, ~4 min, single chapter | 10% | 3% |

Differences under about 10 points at this sample size are noise.
